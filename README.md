# JacobiPlotting
Gnuplot script to plot Jacobi iteration results

Requires [gnuplot](http://www.gnuplot.info/) to be installed.

The script as-is assumes it is running on a system where graphics can be displayed in a popup window.  If this is not desired or not supported (running on a remote server without X11 display capabilities), the first two lines of the script can be uncommented to change the behavior to write a plot to a PNG file.
